☁ Bulut Yedekleme (Ayarlar)

Verilerini internette güvenli sakla. İki seçenek var — en kolayı JSONbin.

☁
Bağlı değil
API Key gir ve bağlan.
Kurulum (2 dakika):
  1. jsonbin.io sitesine git → Sign Up ile ücretsiz üye ol.
  2. Giriş yaptıktan sonra sağ üstteki kullanıcı simgesine tıkla → API Keys.
  3. Secret Key kısmındaki anahtarı kopyala.
  4. Yukarıdaki JSONbin API Key kutusuna yapıştır → Bağlan'a tıkla.

✓ Ücretsiz · OAuth yok · Şifre yok · Her cihazdan erişim

☁
Bağlı değil
Client ID gir ve bağlan.
Kurulum (~10 dk):
  1. Google Cloud Console → sol üstten proje seç → New Project.
  2. Sol menü → APIs & Services → Library → "Google Drive API" ara → Enable.
  3. Sol menü → APIs & Services → OAuth consent screen → External → App name yaz → Save → Test users altına Gmail'ini ekle.
  4. Sol menü → APIs & Services → Credentials → + Create Credentials → OAuth client ID → Application type: Web application → Authorized JavaScript origins'e http://localhost:8000 ekle → Create.
  5. Açılan pencereden Client ID'yi kopyala → yukarıya yapıştır → "Google'a Bağlan".

Not: python -m http.server 8000 ile çalıştırılmalı (file:// değil)
